# RemoteWard Landing Page 🏥✨

A beautifully animated, highly responsive landing page built for **RemoteWard**—an application designed to keep patients and caregivers connected effortlessly. 

This project demonstrates a strong command of modern frontend development, UI/UX design principles, and complex animations to create a premium user experience.

## 🚀 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) for fluid, physics-based interactions and scroll-triggered animations.
- **Icons:** [Lucide React](https://lucide.dev/) for crisp, consistent vector icons.
- **Language:** TypeScript for type safety and robust code architecture.

## 🌟 Key Features (Recruiter Highlights)

- **Complex Scroll Animations:** Implemented staggered, scroll-aware animations using Framer Motion (fade-ups, scale-ins, and complex container staggering) that trigger smoothly as the user navigates down the page.
- **Modern UI/UX Patterns:** Features a frosted-glass bottom navigation bar (iOS style), beautifully layered icon badges, dynamic gradients, and background blurs to create depth.
- **Responsive Design:** Fully mobile-optimized layouts utilizing CSS Grid and Flexbox, ensuring a flawless experience across all device sizes.
- **Component Reusability:** Clean architecture with highly modular components (e.g., `StaggerContainer`, `AnimatedSection`, `Logo`) for maintainability and scalability.
- **Interactive UI:** Includes an interactive mini-quiz and floating UI cards that react to user hover states.

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
